This site runs on [Jekyll](http://jekyllrb.com) — a static site generator that turns Markdown files into a blog, with GitHub Pages handling deployment automatically.

To run it locally:

```bash
bundle install
bundle exec jekyll serve --livereload
```

Posts live in `_posts/` and follow the `YYYY-MM-DD-title.markdown` naming convention. Jekyll rebuilds the site whenever a file changes.
